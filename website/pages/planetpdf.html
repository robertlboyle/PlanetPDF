PlanetPDF

A desktop PDF editor for Windows, Mac, and Linux: forms, signatures, redaction, scans, and page cleanup, with the menus and shortcuts people already know.

Everything on the tool strip

Each tool opens its own bar above the page. The colors here match the edge of that bar in the app.

Fill & Sign

Fill in any form, add text anywhere on the page, and place a saved signature or initials with one click. Draw, type, or import your signature, in any color. Text, signatures, and stamps stay movable until you flatten the page.

Digital signatures and protection

Sign with a Digital ID file, the Windows certificate store, the Mac Keychain, or a smart card. Create certified PDFs, check signatures, and protect files with AES-256 passwords or certificates.

Redact

Mark areas by hand or search for Social Security numbers, phone numbers, email addresses, and account numbers. Redaction deletes the content instead of hiding it under a black box, and every redacted file is checked afterward by two separate PDF readers.

Comment

Highlight, underline, and strike out text; add notes with replies, text boxes, callouts, shapes, clouds, and attached files. Comments are standard PDF annotations, so other PDF programs show them too.

Edit PDF

Click a line of text to move it, change it, or restyle it in its own font, even a line with words in several fonts. Move, resize, rotate, and replace images. Add links, headers, footers, watermarks, and Bates numbers.

Organize Pages

Drag pages into order, rotate, insert, replace, extract, and split. Combine PDFs, pictures, and Office files into one document. Every change can be undone, up to 100 steps.

Prepare Form

Turn a plain document into a fillable form: PlanetPDF finds the blanks, lines, check boxes, placeholders, and table cells for you. Add text fields, dropdowns, lists, dates, buttons, signature fields, and QR code or PDF417 barcodes of the answers.

Scan & OCR

Scan straight into a PDF and make scanned pages, and words drawn as outlines, searchable. Optimize Scans straightens pages, removes dark borders and specks, fades show-through, and drops blank pages.

Create, export, and standards

Make PDFs from files, scanners, web pages, and the clipboard. Export to Word, Excel, PowerPoint, HTML, text, and images. Save as PDF/A, PDF/X, or PDF/E, and check a file for compliance first.

Compare, read aloud, and more

Compare two versions of a document word by word. Have pages read aloud in a natural voice that runs on your own computer. Stamps, bookmarks, spell check, Compress PDF, and a full find bar are included.

Built for real offices

Several documents, one window

Files open as tabs. Drag a tab out to give it a window of its own.

The PlanetPDF printer (Windows)

Print from any program to the PlanetPDF printer to make a PDF. On a Mac, use Open in PlanetPDF in the Print window's PDF menu.

Ready for terminal servers

Each person's settings, signatures, and stamps live in their roaming profile.

Nothing is lost

Open files are saved for recovery every few minutes and offered back after a crash.

Clear progress

Long jobs say exactly where they are, such as "Searching page 37 of 120", and can be stopped.

Accessible

Works with screen readers (Narrator, NVDA, VoiceOver) and with the keyboard alone: pages read through Reflow, forms and comments filled in from their panels, F6 between toolbars, page, and panels. It follows Windows contrast themes, and its text can be made up to twice as large.

Scripts and plugins

Every function works from a command line and a local API, and plugins can add menu items, with the permissions you grant them.

Signed updates

PlanetPDF checks for updates, downloads them in the background, and checks each one's signature before it installs.

A full manual

Help ▸ PlanetPDF Help (F1) explains every function, with contents, an index, and search.

For IT (Windows)

Silent install, with or without the natural reading voices:

PlanetPDF-Setup.exe /VERYSILENT /SUPPRESSMSGBOXES
PlanetPDF-Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /COMPONENTS="main"

Where users can't approve the administrator prompt (terminal servers), install updates as SYSTEM:

"C:\Program Files\PlanetPDF\PlanetPDF.exe" --install-updates

To check that an installed copy works: PlanetPDF.exe --self-test report.txt

Installing on Windows

  1. Run the installerWindows may say "Windows protected your PC", because the installer isn't code-signed. Choose More info, then Run anyway.
  2. Choose what to installThe natural reading voices are ticked; untick them to save disk space (Read Out Loud then uses the Windows voices). The PlanetPDF printer is ticked too.
  3. Open PDF files with PlanetPDFLeave "Make PlanetPDF the default app" ticked, and choose PlanetPDF when Windows asks how to open PDF files.

Installing on a Mac

  1. Open the disk imageDouble-click PlanetPDF.dmg in your Downloads folder.
  2. Drag PlanetPDF to ApplicationsThen eject the disk image and open PlanetPDF from Applications. It offers to become your PDF app on its first start.

Installing on Linux

  1. Pick the file for your computerThe AppImage runs on any distribution without installing. The .deb is for Ubuntu, Debian, and Linux Mint; the .rpm for Fedora and openSUSE. Choose ARM64 on a Raspberry Pi or another ARM computer, otherwise the PC version.
  2. AppImage: make it executable and start itIn the file's Properties, allow it to run as a program, then double-click it.
  3. .deb or .rpm: install itOpen it with your software installer, or in a terminal run sudo apt install ./planetpdf_*.deb or sudo dnf install ./planetpdf-*.rpm. PlanetPDF then appears in your applications menu and under Open With for PDF files.
  4. UpdatesPlanetPDF updates itself the way you installed it. The .deb and .rpm ask for an administrator's password to install a new version, and they add PlanetPDF's package repository, so your system's own updates include PlanetPDF too.

Known limits

  • The Mac version is behind: it's {{planetpdf_mac_version}}; the Windows version is {{planetpdf_version}}. See the release notes for what's new.
  • The Linux version is behind: it's {{planetpdf_linux_version}}; the Windows version is {{planetpdf_version}}. See the release notes for what's new.
  • Dynamic XFA forms can't be opened. Hybrid XFA forms work as normal forms.
  • Form scripts from other programs are never run, for safety.
  • The Windows installer isn't code-signed, so Windows shows an unknown publisher on first install.
  • On Linux, converting Word, Excel, and PowerPoint files needs Microsoft Office, so it's available on Windows and the Mac only; there's no PlanetPDF printer (print to a PDF from the print dialog instead), and PDF from Scanner works with network scanners (AirScan). Signing uses a Digital ID file or a smart card.
  • Text drawn as outlines can be made searchable, but not edited as text.
  • Compliance checks catch real problems but aren't a certified validator.
  • Accessible (tagged) PDF files aren't made yet: PlanetPDF itself works with screen readers, but it doesn't add the tags that help screen readers read a PDF in other programs.
