Printing and the PlanetPDF Printer

This chapter covers two things: printing a PDF from PlanetPDF on paper, and the PlanetPDF printer, which lets any other program (Word, Excel, Outlook, a web browser) "print" to a PDF that you save and open in PlanetPDF.

Printing a PDF

PlanetPDF prints to any printer installed on your computer, using the system's own print dialog.

  1. Open the PDF.
  2. Choose File ▸ Print…, press Ctrl+P (⌘P on a Mac), or click the printer button on the main toolbar.
  3. PlanetPDF first checks that the printer is ready (see The printer check). This usually takes a moment.
  4. In the print dialog, choose the printer, the pages, the number of copies, and the paper size.
  5. Click Print. A progress window shows "Printing page 3 of 10…". Click Cancel there to stop.

When the pages have been sent, the status bar says Sent to and the printer's name. PlanetPDF remembers that printer and starts with it the next time you print.

Tip: what you print is the document as it looks now, including changes you haven't saved yet.

Choosing which pages to print

The print dialog offers:

  • All pages.
  • Current page: the page you are looking at.
  • Pages: a range you type, such as 1-3 or 2-5, 8.
  • Selection: shown when you have selected more than one page in the Pages panel (click the thumbnails with Ctrl or Shift held). Only those pages print.

For several copies, set Copies, and tick Collate to get complete sets (1, 2, 3, 1, 2, 3) rather than each page several times in a row (1, 1, 2, 2, 3, 3). If the printer can't make copies itself, PlanetPDF sends the pages that many times in the same order.

How pages fit the paper

PlanetPDF fits every page to the area the printer can print on, so nothing is cut off at the edges:

  • Each page is made as large as it can be without changing its proportions, and centered on the paper.
  • A page whose orientation doesn't match the paper (a landscape page on portrait paper) is turned a quarter turn so it fills the sheet.
  • Pages are sent to the printer as pictures at up to 300 dots per inch, which gives sharp text on office printers.

To print on a different paper size, choose it in the print dialog; the pages are fitted to that size.

The printer check

Some printer drivers, especially for network printers that are turned off or out of reach, can freeze or even close a program the moment it asks them anything. To protect your work, PlanetPDF asks the printer's driver in a separate, short-lived helper program first. If the driver misbehaves, only the helper is affected and PlanetPDF keeps running.

While the check runs you see "Checking that the printer … is ready: 3 of at most 30 seconds… Please wait…". Most printers answer in a second or two. You can click Cancel to stop; nothing is printed. A printer that passed the check isn't checked again until you next start PlanetPDF.

If you pick a different printer in the print dialog, PlanetPDF checks that one too before printing.

When the usual printer doesn't answer

If the printer you used last (or your default printer) fails the check, PlanetPDF tells you why ("The printer “Office Brother” is unavailable (it didn't answer within 30 seconds)") and opens the print dialog with Microsoft Print to PDF (or Microsoft XPS Document Writer) chosen instead, so you can still pick another printer that works. If no such printer is installed either, you see only the message.

The PlanetPDF printer (Windows)

The installer can add a printer named PlanetPDF to Windows (the "The PlanetPDF printer" part of the installation, chosen by default). Printing to it from any program makes a PDF of what you printed: PlanetPDF asks where to save it and can open it straight away, ready to sign, comment, combine, or send.

  1. In any program, choose its Print command.
  2. Choose the printer PlanetPDF and click Print.
  3. PlanetPDF comes forward (it starts if it wasn't running) and asks "Open “…” in PlanetPDF after it's saved?". Click Open It or Don't Open It. Tick Remember my answer if you don't want to be asked again (see Opening the printout).
  4. The Print to PlanetPDF save window appears. It is Windows' own Save dialog, with your Desktop, OneDrive, Dropbox, recent folders, and drives. It starts in the folder you saved a printout to last (the first time, your Documents folder), and the name is the printed document's name.
  5. Change the folder or name if you like and click Save.

If you click Cancel in the save window, the printout is thrown away and the status bar says it wasn't saved. If you chose not to open it, the status bar shows where it was saved.

Tip: the file name comes from what the program calls the document: "Quote 1043.docx" printed from Word becomes "Quote 1043.pdf", and "Org chart.vsdx" from Visio becomes "Org chart.pdf". The document's own extension, a program's own name in front ("Microsoft Word - ") or after it (" - Notepad"), and characters Windows doesn't allow in file names are left out.

Opening the printout

Before the save window, PlanetPDF asks whether to open the printout once it's saved. With Remember my answer ticked, it does the same every time without asking. You can change this at any time in Edit ▸ Preferences… ▸ Documents ▸ After saving: Ask each time, Open the PDF, or Don't open it.

Saving printouts without being asked

If you always want printouts in the same folder, you can skip the save window:

  1. Choose Edit ▸ Preferences… and click Documents.
  2. Under PlanetPDF printer, choose Save printouts in this folder without asking and type the folder or click Browse….
  3. In File name, type how printouts should be named. You can use:
    • {document}: the printed document's name (this alone is the default)
    • {date}: today's date, as year-month-day (2026-10-18)
    • {time}: the time, as hours-minutes-seconds (14-05-32)
    • {user}: your Windows sign-in name
    • {computer}: this computer's name
    For example, {date} {document} gives "2026-10-18 Quote 1043.pdf".
  4. Click Save.

Printouts then go straight into that folder. A printout never replaces an existing file: a second "Quote 1043.pdf" is saved as "Quote 1043 (2).pdf". The name template is also used for the suggested name in the save window when you are asked.

If the folder can't be used (a network drive that isn't connected, for example), PlanetPDF says so and shows the save window instead.

Settings for IT

IT can set a printout folder and name for everyone on a computer with two environment variables:

  • PLANETPDF_PRINT_FOLDER: the folder printouts are saved to without asking (environment variables such as %USERPROFILE% in it are filled in).
  • PLANETPDF_PRINT_NAME: the file name template, with the same {document}, {date}, {time}, {user}, and {computer}.

A folder or name you set in Preferences comes first; the environment variables apply when yours are empty. When IT has set a folder, the Documents page of Preferences says so.

Terminal servers. The PlanetPDF printer works for each person signed in to a shared computer (Remote Desktop, Citrix). Every printout goes only to the person who printed it, in their own session, and is saved with their own rights, so their redirected Documents folder and network drives work.

How it works. The PlanetPDF printer uses Windows' own Microsoft Print To PDF driver. A small Windows service, the PlanetPDF Print Service, receives each job only from Windows' print spooler (or the print helpers the spooler starts), keeps it in a folder only administrators can read (checked each time it starts: a folder anyone else made or can open is moved aside and made again), finds who printed it (Windows says who is writing the job), and hands it to that person's PlanetPDF: to the session of that very account, so two people whose user names are the same (one of the computer's own accounts and one of the domain's, say) never get each other's printouts. When it can't tell for sure whose a printout is, it keeps it in that folder (held-….pdf) and logs it, rather than give it to someone who may not have printed it. Held printouts are kept for 30 days, and at most 1 GB of them (the oldest go first); a single printout larger than 4 GB is thrown away. If the service ever stops by itself, Windows starts it again. The service holds the printer's connection for as long as it runs, so no other program can take it; if another program already has it when the service starts, the printer is paused (jobs wait in the queue) and the log says so. Its log is %ProgramData%\PlanetPDF\Spool\printer.log (administrators only). In the install folder, printer\planetpdf-printer-setup.exe status reports whether the service, port, and printer are in place, and whether only administrators can change the service's program and PlanetPDF's folder; install and uninstall add or remove them (run as administrator; the installer does this for you). Because the service runs with system rights, install refuses to add it where other users could replace its program, and the service notes it in its log if it finds itself in such a folder: run PlanetPDF's installer again, which closes the folder to everyone but administrators.

Printouts while PlanetPDF is closed

You don't need PlanetPDF open to print to it: the printer starts PlanetPDF for you. If PlanetPDF couldn't be started at that moment (for example, a session that was disconnected), the printout waits, and the next time you start PlanetPDF it asks about each printout that is waiting, oldest first, in the usual way.

Printing to PlanetPDF on a Mac

On a Mac, every print dialog has a PDF menu at the bottom left. PlanetPDF adds Open in PlanetPDF to it (it does this each time it starts, so it is always current).

  1. In any app, choose File ▸ Print… (⌘P).
  2. Click the PDF menu and choose Open in PlanetPDF.
  3. PlanetPDF asks whether to open the printout, then shows the Mac's own Save dialog, exactly as on Windows (or saves to your printout folder without asking, if you set one in Preferences).
