Creating, Converting, and Comparing

This chapter covers making new PDFs from other files, web pages, the clipboard, or a blank page; exporting a PDF to Word, Excel, PowerPoint, pictures, and other formats; saving archival and print-ready copies (PDF/A, PDF/X, PDF/E) and checking them; comparing two versions of a document; and the document's properties.

The Create PDF tool

Open the Create PDF tool from the tool strip on the right or from Tools ▸ Create PDF. The middle of the window shows the start page, "Create a PDF from any format", with the choices in a list: Single File, Multiple Files, Scanner, Web Page, Clipboard, and Blank Page. Click a choice, set its options on the right, and click the big blue button under them. The tool's bar has the same commands as buttons: PDF from File, Scanner, Web Page, PDF from Clipboard, Blank Page, Combine Files, Multiple PDF Files, Portfolio, and Create Form.

The same commands are on the File ▸ Create menu. Every new PDF is saved where you choose and opens in a tab of its own; the files you started from aren't changed.

From a single file

  1. Choose File ▸ Create ▸ PDF from File…, or on the start page click Single File, then Select a File (or the large file tile).
  2. Pick the file and click Open. On the start page, click Create.
  3. Choose where to save the new PDF. The Save window starts in the folder the file came from, with the same name, so clicking Save puts the PDF beside it. The next file you choose starts in that folder too. (A file opened from a temporary folder, such as inside a zip, is offered your Documents folder instead. Combine Files and Create Multiple PDF Files do the same with the first file in the list.)

These kinds of file can be turned into a PDF this way:

  • Pictures: PNG, JPEG, TIFF (every page of a multi-page TIFF), BMP, GIF, JPEG 2000, JPEG XR, PNM/PBM/PGM/PPM.
  • Text files (.txt): laid out on Letter pages with margins, wrapped, as many pages as needed.
  • XPS and OpenXPS, EPUB, FB2, MOBI, and CBZ e-books and comics, and SVG drawings.

On the start page, tick Advanced: recognize text afterwards (OCR) to make the text of a scan or picture searchable straight away (see Recognizing text).

Word, Excel, and PowerPoint files are turned into PDFs through Microsoft Office itself, so Office must be installed on the computer. A window says while Word, Excel, or PowerPoint works on it. On Windows, macros in the file are always turned off while Office opens it for PlanetPDF, whatever Office's own settings say, so a file you received can't run code this way. Office is given a copy with the file's links to other places taken out (an attached template, linked pictures, linked data), so converting never reaches a server the file names; its hyperlinks stay. A file in an older format (.doc, .xls, .ppt, .rtf) that came from the internet or an e-mail can't be cleaned that way, so PlanetPDF says so instead: open it in Office (it opens in Protected View), save it in the newer format, and convert that. For many Office files at once, use Create Multiple PDF Files.

Multiple files

On the start page, click Multiple Files, choose one of the three options, and click Next:

  • Combine files into one PDF: PDFs and pictures, in the order you choose (see Combining files).
  • Create a PDF from each file: a separate PDF for every file (see Create Multiple PDF Files).
  • PDF Portfolio: the files kept together, unchanged, inside one PDF (see PDF Portfolio).

Combining files into one PDF

  1. Choose File ▸ Create ▸ Combine Files into a Single PDF… (or Combine Files on the Create PDF bar).
  2. Click Add Files… to add PDFs and pictures. Drag them, or use Move Up and Move Down, to put them in order; Remove takes one out.
  3. For pictures, choose Image pages: Same size as the image, Letter (fit the image), or A4 (fit the image).
  4. Tick Recognize text (OCR) so the result is searchable if the files are scans.
  5. Click Create PDF… and choose where to save it.

If one of the PDFs is password protected, PlanetPDF asks for its password. The progress window counts the files ("Adding file 2 of 5").

Create Multiple PDF Files (one PDF per file)

  1. Choose File ▸ Create ▸ Create Multiple PDF Files….
  2. Click Add Files… or Add Folder… to list the files.
  3. In Save in:, choose the folder for the new PDFs (Browse…).
  4. Click Create PDFs.

Each file becomes a PDF of the same name: pictures, text, XPS, EPUB, and SVG files, and, when Microsoft Office is installed, Word (.doc, .docx, .rtf, .odt…), Excel (.xls, .xlsx, .csv, .ods…), and PowerPoint (.ppt, .pptx, .odp…) files. The window says which Office programs it will use. Existing files are never overwritten. At the end PlanetPDF says how many files were done and lists any it couldn't convert, with the reason.

  • Word documents keep their headings as bookmarks. If the document has a table of contents but no headings Word can turn into bookmarks, PlanetPDF adds a bookmark for each contents entry.
  • On a Mac, macOS asks once per Office program whether PlanetPDF may control it, and once for access to Office's files: click OK / Allow. If Word was already open, a copy named "(PlanetPDF copy)" may stay open in it afterwards.

PDF Portfolio

A portfolio keeps several files of any kind together, unchanged, inside one PDF. Its first page lists them, and viewers that know portfolios show them as a list.

  1. Choose File ▸ Create ▸ PDF Portfolio….
  2. Add the files and put them in order.
  3. Click Create Portfolio… and choose where to save it.

The portfolio opens with the Attachments panel showing its files. Select one and click Save As… to save a copy of it; PlanetPDF never runs an attached file.

From a scanner

Choose File ▸ Create ▸ PDF from Scanner…, or Scanner on the start page. See Scanning paper into a PDF.

From a web page

PlanetPDF prints a web page to a PDF through Microsoft Edge (or Google Chrome when Edge isn't there; on a Mac also Chromium or Brave), without opening a browser window.

  1. Choose File ▸ Create ▸ PDF from Web Page…, or Web Page on the start page.
  2. Type the address, for example www.example.com (PlanetPDF adds https://), or the path of an .html file on your computer.
  3. Click OK. The progress window counts the seconds the page takes to load ("12 of at most 120 seconds"); Cancel stops.
  4. Choose where to save the PDF.

Only web (http, https) addresses and files can be captured. The page is loaded in a fresh, empty browser profile, so pages that need you to sign in show as they do for a visitor who isn't signed in. To add a web page to the open document instead, choose File ▸ Insert Pages ▸ From Web Page….

From the clipboard

Copy a picture (for example a screenshot) or some text in any program, then choose File ▸ Create ▸ PDF from Clipboard (or Clipboard on the start page). A picture becomes one page its size (shrunk to fit Letter if larger); text is laid out on Letter pages. If the clipboard holds neither, PlanetPDF says so. File ▸ Insert Pages ▸ From Clipboard… adds it to the open document instead.

A blank page

Choose File ▸ Create ▸ Blank Page (or Blank Page on the start page) for a new PDF with one empty Letter-size page. Add text with Edit ▸ Add Text, or start a form on it with File ▸ Create ▸ Create Form… (see Forms).

Exporting a PDF to other formats

Exporting makes a new file in another format. The PDF itself isn't changed, and any unsaved changes are included in the export. There are three ways to start:

  • File ▸ Export To and the format.
  • The Export PDF tool: its start page, "Export your PDF to any format", shows the document on the left and the kinds of file in a list (Microsoft Word, Spreadsheet, Microsoft PowerPoint, Image, HTML Web Page, More Formats). Choose one, pick a format with its round button, and click Export. The ⚙ beside a format opens its settings. The tool's bar has buttons for the same formats.
  • Ctrl+E opens the Export window with the format you used last.

The Export window

  1. Format: the kind of file. You can change it here.
  2. Pages: the pages to export, for example 1,5,8-12. Pages are exported in the order typed. The pages selected in the Pages panel are filled in.
  3. The format's own settings, if it has any (see the table below). A note under them says what to expect from the format.
  4. Click Export…, then choose the file name and folder.

The progress window counts the pages ("Exporting page 3 of 10"). Formats that make one file per page name them after the file you choose, with the page number added (for example Report_p01.png, Report_p02.png). PlanetPDF remembers the format and settings for next time.

AI text reading (Unlimited-OCR)

For exports to Word, Word 97-2003, Rich Text, text, accessible text, and HTML, PlanetPDF can read the pages with Unlimited-OCR, an AI model. It reads the whole document at once and writes one flowing document: headings as Word headings, paragraphs joined across lines and pages, lists, and tables as real tables, all in reading order. It works best on scanned documents, which the usual conversion can only turn into separate lines of text. Pictures and the page layout aren't kept.

  1. Choose File ▸ Export (Ctrl+E) and one of the formats above.
  2. Tick Read the pages with AI (Unlimited-OCR), then click Export… and choose where to save.
  3. The first export loads the model onto the graphics card, which takes a little while; then it counts the pages as it reads them ("Reading page 3 of 12"). The model stays loaded for a few minutes, so the next export starts at once (Preferences ▸ Performance).

What it needs: the optional PlanetPDF AI Text Reading add-on (its own installer, about 10 GB), and a Windows computer with an NVIDIA graphics card with about 8 GB of memory and a current NVIDIA driver. Without them the box is grayed out, and pointing at it says why. Everything runs on this computer: no document is sent anywhere.

PDF/A, PDF/X, and PDF/E

Some places ask for a PDF that follows a standard:

  • PDF/A (PlanetPDF makes PDF/A-2b) is for long-term archiving: courts, government agencies, and records departments often require it. Everything needed to show the file is inside it (fonts, color profile), and nothing that could stop it showing the same way in years to come (scripts, sound, video, links to other files) is allowed.
  • PDF/X (PDF/X-3) is for a printing press: colors in CMYK, no transparency, every page with a trim box.
  • PDF/E (PDF/E-1) is for engineering documents such as drawings.

Saving in a standard always makes a copy; the open document doesn't change. These conversions use Ghostscript, which comes with PlanetPDF. If it is missing, PlanetPDF says so: ask IT to install it.

Saving a copy as PDF/A, PDF/X, or PDF/E

  1. Choose File ▸ Save as Other ▸ Archivable PDF (PDF/A)…, Press-Ready PDF (PDF/X)…, or PDF/E…, or open the PDF Standards tool and click Save as PDF/A, Save as PDF/X, or Save as PDF/E.
  2. Choose a name for the copy. PlanetPDF suggests "name_pdfa.pdf" (or _pdfx, _pdfe). It can't replace the open document.
  3. The progress window counts the pages; Cancel stops.

Before converting, PlanetPDF fixes on the copy what the standard forbids: it removes scripts and forbidden actions, sound, video, and attached files, sets comments to print and gives them a look, and (for PDF/X) sets each page's trim box. Ghostscript then embeds the fonts, adds the color profile and the standard's markings, and (for PDF/X) converts colors to CMYK and flattens transparency. At the end PlanetPDF lists what was changed. PDF/A and PDF/X copies can't be password protected: the standards don't allow it.

Check Compliance

Check Compliance checks the open document against PDF/A, PDF/X, or PDF/E and tells you what, if anything, stands in the way.

  1. Open the PDF Standards tool and click Check Compliance. The check runs at once against PDF/A.
  2. To check against another standard, choose it in Check against: and click Analyze.
  3. Read the summary at the top ("N problems to fix", "No problems found…", or "This file meets…"), then the list of checks.

Each check shows one of these results:

ResultMeaning
PassThe document meets this rule.
N/AThe document doesn't use what's checked (for example, it has no comments), so there is nothing to fix. Counts as a pass.
Added when savedSomething every file of the standard carries, such as its identification, metadata, color profile, or a PDF/X trim box. It is added when you save in that format, so it is never a problem.
WarningWorth a look, but not a failure.
FailA real problem, such as fonts not embedded, scripts or forbidden actions, sound or video, comments that don't print, password protection, or (for PDF/X) transparency or RGB colors. Each failure has a "How to fix:" line under it, and the pages it affects; double-click a page to go to it.

The checks are: the file is marked as the standard, metadata, color profile (output intent), not password protected, document title, all fonts are embedded, no scripts or forbidden actions, no sound, video, 3D, or attached files, comments and fields print as they look, and, for PDF/X, no transparency, no RGB colors, and a trim box on every page.

Fix and Save

When something fails, the main button is Fix and Save as PDF/A… (or PDF/X, PDF/E); when nothing fails it is Save as PDF/A…. Click it and choose a name. PlanetPDF makes a corrected copy the same way as Save as, checks the copy again, and shows the copy's results: what was changed, and anything "Not fixed automatically" that you must change in the document yourself before trying again.

  • Open Fixed Copy opens the copy in a new tab.
  • Save Report… saves the results as a text file.

Note: Check Compliance covers the rules that most often fail. It isn't a certified validator: when an archive or a print shop must be certain, check the copy with their validator too.

Comparing two versions

Compare Files finds the text that was added, removed, or changed between two versions of a document.

  1. Open the newer version.
  2. Choose View ▸ Compare Files or Tools ▸ Compare Files (or click Compare Files on the tool strip).
  3. Choose the older version and click Open. If it is password protected, PlanetPDF asks for the password.

The progress window counts the pages compared. Then a window titled "Compare with file" opens beside the document. It stays open while you work, and shows:

  • Which file is Old and which is New, and a summary ("3 changed, 2 added, 1 removed", and the page counts if they differ). If the text is the same, it says "No differences in the text."
  • A list of the changes, each with its kind (Added, Removed, Changed), its page, and the words. Point at one to see the old and new text.

Every change is highlighted in the open document. Click a change in the list to go to it; it is highlighted more strongly. Removed text exists only in the other file, so clicking it just says so in the status bar.

  • Swap Old and New: treat the open document as the old version instead.
  • Save Comparison Report…: saves a PDF report: summary pages, then the old and new pages side by side with the changes marked in red (removed), green (added), and amber (changed). PlanetPDF suggests "name - comparison.pdf"; it can't be one of the two files being compared.
  • Close closes the window and the highlights go away.

Compare looks at the words, not at pictures, layout, or formatting. Scans need their text recognized first (see Recognizing text).

Document properties

Choose File ▸ Properties… (Ctrl+D) to see facts about the document and change its description.

  • Description: Title, Author, Subject, and Keywords. These are stored in the PDF; search tools, document systems, and some viewers' title bars show them. Change them and click Save Changes. The change is one undo step; save the document to keep it.
  • File (read only): location, size, number of pages, page size, PDF version, when it was created and last modified, the program it was created with and the PDF producer, whether it is password protected, digitally signed, or has form fields, and the fonts it uses. You can select and copy these.

To remove the description and other hidden information before sharing a file, see Protecting and Redacting.
