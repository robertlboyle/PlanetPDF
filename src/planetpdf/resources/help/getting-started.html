Getting Started

This chapter covers installing PlanetPDF, opening files, finding your way around the window, saving your work, undoing changes, getting your work back after a crash, updates, and where PlanetPDF keeps your settings. If you have used Adobe Acrobat before, much of it will look familiar: PlanetPDF follows Acrobat's menus, tool names, and keyboard shortcuts.

Installing PlanetPDF

PlanetPDF runs on Windows and on Apple Silicon Macs. Each computer installs it once, and every person who signs in to that computer can use it.

Installing on Windows

The Windows installer is PlanetPDF-Setup.exe. It installs PlanetPDF for everyone who uses the computer, so it needs an administrator's OK.

  1. Double-click PlanetPDF-Setup.exe. If Windows asks whether to let the app make changes, click Yes (or ask your administrator to sign in).
  2. If Windows SmartScreen says it protected your PC from an unrecognized app, click More info, then Run anyway. The installer isn't signed with a code-signing certificate, so Windows shows it as coming from an unknown publisher.
  3. Choose where to install it (the usual place is C:\Program Files\PlanetPDF) and click Next.
  4. Choose the components (see below) and click Next.
  5. Choose the extra tasks (see below), check the summary, and click Install. While the files are copied, the installer shows tips about what PlanetPDF can do, a new one every few seconds; click Next tip to see the next one at once.

PlanetPDF appears in the Start menu and, unless you untick it, on the desktop.

Components: reading voices and the PlanetPDF printer

The installer offers three kinds of installation: Full installation (with natural reading voices), Without the natural reading voices (smaller), and Custom, where you tick each part yourself.

ComponentWhat it is
PlanetPDFThe program itself, with text recognition (OCR) and Ghostscript for saving PDF/A, PDF/X, and PDF/E files. Always installed.
Natural reading voicesThe voices View ▸ Read Out Loud uses (about 460 MB). Without them, PlanetPDF reads with the Windows voices, and you can download the natural voices later from Preferences ▸ Read Out Loud. See Read Out Loud.
The PlanetPDF printerA printer named PlanetPDF that every program on the computer can print to; what you print becomes a PDF that opens in PlanetPDF. See Printing and the PlanetPDF Printer.

Extra tasks: default PDF app, desktop shortcut, PATH

  • Make PlanetPDF the default app for opening PDF files (ticked). Windows doesn't let an installer choose your default apps for you, so at the end of Setup Windows asks "How do you want to open .pdf files?". Choose PlanetPDF there (and Always, if Windows offers it) to make PDF files open in PlanetPDF when you double-click them. If PlanetPDF already opens your PDF files, Setup leaves it as it is and asks nothing. You can do this later from Edit ▸ Preferences ▸ General, Make PlanetPDF the Default App for PDF Files.
  • Create a desktop shortcut (ticked).
  • Let command prompts and scripts run planetpdf (ticked). Adds PlanetPDF's folder to the system PATH, so you can type planetpdf in a command prompt. Uninstalling takes it out again. See Scripts, Programs, and Plugins.

All three are ticked every time Setup runs, also when you install a newer version over an older one.

For IT: Setup runs silently with /VERYSILENT /SUPPRESSMSGBOXES; add /COMPONENTS="main" to leave out the voices. A silent install doesn't open the Default apps page. Uninstalling (Windows Settings ▸ Apps) removes every installed version and the voices; your own settings and signatures stay in your profile folder.

Installing on a Mac

The Mac version comes as a disk image, PlanetPDF.dmg. It runs on Macs with Apple Silicon (M1 and later) and macOS 15 (Sequoia) or later. It's signed and notarized by Apple, so it opens without warnings.

  1. Double-click PlanetPDF.dmg.
  2. In the window that opens, drag PlanetPDF onto the Applications folder.
  3. Eject the disk image, then open PlanetPDF from Applications or Launchpad.
  4. The first time it starts, PlanetPDF asks whether it should open your PDF files. Click yes to make it your default PDF app (you can also do this later in PlanetPDF ▸ Preferences ▸ General).

The Mac app doesn't include the natural reading voices: Read Out Loud uses the macOS voices until you download them (PlanetPDF offers this the first time you use Read Out Loud). Instead of a PlanetPDF printer, the Mac has Open in PlanetPDF in the PDF menu of every print dialog. On a Mac, shortcuts shown with Ctrl in this manual use ⌘ (Command) instead.

Installing on Linux

The Linux version runs on Ubuntu 24.04, Debian 13, Fedora 40, or newer, on PCs (x86-64) and on ARM64 computers (such as a Raspberry Pi 5). It comes three ways; pick the one that fits your system (aarch64 / arm64 in the file name is for ARM64, x86_64 / amd64 for PCs):

  • AppImage (any distribution, nothing to install): make the file executable (in the file manager's Properties, or chmod +x PlanetPDF-*.AppImage), then double-click it.
  • .deb (Ubuntu, Debian, Linux Mint): open it with your software installer, or run sudo apt install ./planetpdf_*.deb.
  • .rpm (Fedora, openSUSE): open it with your software installer, or run sudo dnf install ./planetpdf-*.rpm.

The .deb and .rpm add PlanetPDF to your applications menu, to "Open With" for PDF files, and the planetpdf command. PlanetPDF updates itself the way it was installed: when a new version is ready it asks, and installs it when you close PlanetPDF. The AppImage replaces its own file; the .deb and .rpm ask for an administrator's password, since the system's package tool installs them. Installing the .deb or .rpm also adds PlanetPDF's package repository, so your system's own updates (Software Updater, apt upgrade, dnf upgrade) offer new versions too; to stop that, delete /etc/apt/sources.list.d/planetpdf.sources or /etc/yum.repos.d/planetpdf.repo. Read Out Loud downloads the natural voices the first time you use it.

Starting PlanetPDF and opening files

Start PlanetPDF from the Start menu (Windows), Applications (Mac), or your applications menu (Linux). With no document open, the window shows the menus and tools; open a file to begin.

File ▸ Open

  1. Choose File ▸ Open (or press Ctrl+O, or click the folder button at the left of the main toolbar).
  2. Pick one or more PDF files and click Open. Each opens in its own tab.

A file protected with a password asks for it first. A file encrypted for certain people (certificate security) opens with your Digital ID: PlanetPDF tries the certificates in your Windows certificate store or Mac Keychain first, then asks for a Digital ID file. See Protecting and Redacting.

Dragging files into PlanetPDF

Drag one or more PDF files from File Explorer (or the Finder) onto PlanetPDF's window. Each opens as a new tab. Dropping a file on the Pages panel instead inserts its pages into the open document, at the place you drop it (see Organizing Pages).

Double-clicking a PDF

When PlanetPDF is your default PDF app, double-clicking a PDF in File Explorer opens it in PlanetPDF. Otherwise right-click the file and choose Open with ▸ PlanetPDF.

One running copy

PlanetPDF runs once per person. If it's already running when you open another file (by double-clicking it, for example), the file opens as a new tab in the PlanetPDF window you used last, and that window comes to the front. That's true even while PlanetPDF is still starting: files you open in those first seconds wait and open as tabs as soon as its window is ready. If the file is already open, PlanetPDF just shows it. On a terminal server, everyone signed in has their own copy.

A file is never open twice, so you can't close one copy without saving while the changes are in another. If a second PlanetPDF is running anyway (one started with --new-instance, or one that stopped answering), opening a file it already has shows the file in that PlanetPDF instead. If that PlanetPDF can't be reached, a message says File Already Open: switch to its window to work on the file.

Recent files

The File menu lists the last five files you opened, numbered, just above View All Recent Files…. Click one to open it. View All Recent Files… lists every file you've opened recently: choose one and click Open (or double-click it).

Reopen PDFs from Last Session

File ▸ Reopen PDFs from last session opens again every PDF that was open when you last closed PlanetPDF, in every window. It's grayed out when none of those files can be found.

A tour of the window

From top to bottom, PlanetPDF's window has the menu bar, the main toolbar, the bar of the tool that's open, the document tabs, and the pages. The tool strip runs down the right edge, and the Pages and Bookmarks panel flies out from the left (or right) edge.

The menu bar

The menus are those of classic Adobe Acrobat: File, Edit, View, Tools, Window, and Help. Every command and its shortcut is listed in the Menu Reference. Help ▸ Keyboard Shortcuts lists every shortcut. To hide the menu bar for more room, choose View ▸ Show/Hide ▸ Menu Bar (F9); press F9 again to bring it back.

The main toolbar

The main toolbar holds the commands you use most, from left to right:

  • Open, Save, Print, and Find.
  • Previous Page and Next Page, the page number box, and the page count ("3 / 10").
  • The Select arrow and the Hand (see Select and Hand).
  • Zoom Out, Zoom In, the zoom box, and the Page Display and Zoom menu (fit, actual size, and the page layouts).
  • Quick tools: add a sticky note, highlight text, and rotate the view counterclockwise or clockwise (this only turns how pages are shown; the file isn't changed).
  • While Read Out Loud is activated: the reading buttons, the voice menu, and the volume slider (see Read Out Loud).

View ▸ Show/Hide ▸ Toolbar Items ▸ Main Toolbar (F8) hides and shows it. View ▸ Show/Hide ▸ Button Labels chooses No Labels (icons only), Default Labels, or All Labels (a name beside every icon).

The open tool's bar

When you open a tool (Comment, Organize Pages, Redact, and so on), its bar appears on its own row under the main toolbar. The tool's name is on the left, with a colored edge in the tool's color; its commands are in the middle; and Close (✕) on the right closes the tool. You can also close it with Tools ▸ Close Tool. Tools that work with text also show a text format bar (font, size, bold, italic, underline, strike-out, color) on a row of its own while it applies.

The tool strip

The column of colored icons down the right edge is the tool strip. Click an icon to open that tool (the same as choosing it from the Tools menu); hover over one to see its name. The tools are Create PDF, Edit PDF, Export PDF, Organize Pages, Compress PDF, Bookmarks, Comment, Stamp, Fill & Sign, Prepare Form, Protect, Redact, Scan & OCR, Optimize Scans, Compare Files, and PDF Standards. The open tool shows white on a dark tile.

View ▸ Show/Hide ▸ Tools Pane (Shift+F4) hides and shows the strip.

Putting the tools in your own order

  1. Press on a tool's icon in the strip and drag it up or down. The icon dims, and a blue bar shows where it will go.
  2. Let go where you want it. PlanetPDF remembers the order.

Press Esc while dragging to cancel. To go back to the original order, right-click the strip and choose Reset Tool Order.

The Pages and Bookmarks panel

The Pages panel (page thumbnails) and the Bookmarks panel share one panel at the side of the pages. Two buttons open it: Pages and Bookmarks. Click a button to fly the panel out; click the same button again, or the » button in the panel, to collapse it. F4 (View ▸ Show/Hide ▸ Navigation Panes ▸ Show/Hide Navigation Pane) does the same. Drag the panel's edge to make it wider or narrower; the thumbnails grow and shrink with it. The bottom of the panel says which page you're on ("Page 3 of 10").

The panel is on the left by default, with its two buttons on a slim bar along the left edge. To move it to the right (its buttons then sit at the top of the tool strip), choose View ▸ Show/Hide ▸ Navigation Panes ▸ Pages Panel on the Right; Pages Panel on the Left moves it back. With no document open, the panel is closed and its buttons are grayed; it comes back when you open a file. A file that has bookmarks opens with the Bookmarks panel showing. See The Pages panel and The Bookmarks panel.

Other panels (Attachments, Comments, Signatures, Fill Form, Redaction, Undo History) are listed under View ▸ Show/Hide ▸ Navigation Panes. Most tools open their own panel when you open the tool; only one tool panel shows at a time.

Tabs: several documents in one window

Every document you open gets a tab above the pages. Click a tab to switch to it, or press Ctrl+Tab (next document) and Ctrl+Shift+Tab (previous document); Ctrl+F6 and Ctrl+Shift+F6 do the same. Drag a tab sideways to change the order. Each tab keeps its own zoom, scroll position, and undo history.

Click a tab's ✕ or press Ctrl+W (File ▸ Close File) to close the current document; PlanetPDF asks first if it has unsaved changes. Right-click a tab for Move to New Window, Close, and Close Other Tabs. To hide the tab bar, turn off View ▸ Show/Hide ▸ Document Tabs and switch documents with the Window menu.

Popping a document out into its own window

To see two documents side by side (and drag pages between them), give one a window of its own. Any of these works:

  • Drag its tab out of the tab bar and let go outside the window. Let go over another PlanetPDF window instead to move it there.
  • Right-click its tab and choose Move to New Window.
  • Choose Window ▸ Move to New Window.
  • In the Window menu, click the pop-out icon at the right end of the document's name.

The document keeps its unsaved changes and its undo history. All the windows belong to the same running PlanetPDF and share your settings.

The Window menu

  • Cascade and Tile ▸ Horizontally / Vertically arrange PlanetPDF's windows.
  • Move to New Window gives the current document a window of its own.
  • Next Document and Previous Document switch tabs.
  • Close All closes every document (asking about unsaved changes).
  • Below those, every open document is listed, grouped by window, with a check mark by the current one. Click a name to show it; click the icon at the right end (or right-click the name) to move it to a new window.

Select and Hand

Two buttons on the main toolbar decide what a plain click on the page does when no other tool is on:

  • Select (the arrow): click comments, signatures, stamps, and other items to select them; drag over text to select it for copying. Links and form fields work as usual.
  • Hand: drag the page to move around it. Form fields can still be filled in with the Hand, as in Acrobat.

Choosing the Select arrow also switches off whatever tool was on.

Tools that stay on, and tools that don't

Most tools stay on after you use them, so you can add several highlights, boxes, or fields in a row. They stay on until you click the Select arrow, choose another tool, or close the tool's bar. Esc only drops what you're in the middle of drawing; the tool stays on. These tools stay on:

  • Every Comment tool (notes, highlights, shapes, text boxes, and so on).
  • Edit PDF's Add Text, Eraser, and Link.
  • Fill & Sign's Add Text and its ✗ ✓ ○ — • symbols.
  • Prepare Form's field tools.
  • The redaction box (Mark Area for Redaction) and Select Text.

Some tools make sense only once, so they turn themselves off after one use and go back to the Select arrow (Esc cancels them before you use them):

  • Stamps, seals, signatures, and initials.
  • Attach File.
  • Edit PDF's Add Image (the new picture is selected afterwards).
  • Cropping a page by drawing a box, Take a Snapshot, and Marquee Zoom.

Dynamic Zoom and the Loupe Tool stay on until you press Esc.

While a tool is on, pressing on an item that's already selected (or on its handles) moves or resizes it instead of using the tool.

Seeing which tool is on

The button of the tool that's on is shown reversed: a white icon on a dark tile, with bold text if it has a label (in the dark theme, on a bright blue tile). The tool's icon on the tool strip is highlighted the same way, and the Tools menu puts a check mark by the open tool. When the tool turns off, its button goes back to normal.

Saving your work

Changes stay in PlanetPDF until you save them. The tab and the window title show which documents have unsaved changes.

  • File ▸ Save (Ctrl+S) writes the changes into the file.
  • File ▸ Save As… (Ctrl+Shift+S) saves under a new name or in another folder; the tab then shows the new file.
  • File ▸ Revert throws away every change since the last save and opens the file again (it asks first).

Closing a document, a window, or PlanetPDF asks about each document with unsaved changes: Save, Discard, or Cancel.

When you save, PlanetPDF also embeds any fonts the PDF only names but which are installed on this computer, so the file looks the same everywhere; the status bar names fonts it couldn't find. If the document has redaction marks that haven't been applied, the status bar reminds you that the content under them is still there.

Saving a long document (30 pages or more, or a file of 15 MB or more) shows a window with each step: "Step 1 of 3: embedding font 2 of 5", "Step 2 of 3: writing 120 pages…", "Step 3 of 3: opening the saved file…". A save can't be stopped once it has begun, so the window has no Cancel button.

Files from a zip file or an e-mail

A PDF opened straight from a zip file in File Explorer, or from an e-mail attachment, is really a copy in a temporary folder, which Windows or the e-mail program empties without asking (for a zip file, as soon as its window closes). PlanetPDF won't save there: when you open such a file the status bar says so, and Save asks Choose Where to Keep This File and opens Save As in a lasting folder (the last one you used, or Documents). Choosing a temporary folder in Save As is refused, and you are asked again. Until it is saved somewhere lasting, auto-save keeps a recovery copy of your changes.

Saving a signed document

A digitally signed document is saved by adding your changes to the end of the file, so the existing signatures stay intact. Some changes (moving or deleting pages, for example) would break the signatures; then PlanetPDF warns Signatures Will Be Invalidated and saves only if you click Save. See Signatures.

Saving a password-protected document

Saving a password-protected or certificate-encrypted document keeps its protection: the saved file needs the same password (or Digital ID) to open. New files made from it (extracted pages, a smaller copy, a redacted copy, and so on) ask whether to protect them too. See Protecting and Redacting.

Undo, Redo, and Undo History

Every change you make to a document can be undone.

  • Edit ▸ Undo (Ctrl+Z) takes back the last change; the menu says which one ("Undo Move Text").
  • Edit ▸ Redo (Ctrl+Shift+Z) puts it back.
  • Edit ▸ Undo History opens a panel listing every change since the file was opened (up to 100 steps). Click any row to go back to that point; click a later row to go forward again. The top row, "(as opened or last saved)", is the file as it was.

Each document has its own undo history, which follows it to another tab or window. Undoing back to the last save makes the document "unchanged" again. A few things can't be undone and say so before you do them: applying redactions over the original file and digitally signing. Several nudges of the same item with the arrow keys count as one step.

Auto-save and recovery after a crash

While a document has unsaved changes, PlanetPDF quietly keeps a recovery copy on this computer every 5 minutes. The copy is removed when you save, close the document, or undo back to the last save. If the file is password-protected, so is the recovery copy.

If PlanetPDF closes unexpectedly (a crash or a power cut), the next time it starts it shows Recover Unsaved Work with the documents it has copies of:

  • Restore saves the copy as "name (recovered).pdf" next to the original and opens it. The original file isn't changed; use View ▸ Compare Files to see what differs.
  • Discard throws the copy away (it asks first).
  • Decide Later keeps the copies and asks again next time.

To change how often copies are made, or to turn it off, use Edit ▸ Preferences ▸ Documents, Auto-save for recovery every (0 = Off). See Preferences.

Updates

PlanetPDF can check for a newer version and install it for you. Every update is checked (digitally signed and verified) before it's installed.

  1. Choose Help ▸ Check for Updates…. PlanetPDF asks the update server for the latest version and says if you already have it.
  2. If there's a newer version, it downloads in the background (counted in MB), then PlanetPDF asks what to do: Restart Now (closes PlanetPDF, asking about unsaved work, installs, and starts again), When I Close PlanetPDF, or Skip This Version.
  3. On Windows, installing needs one administrator OK (the Windows prompt). On a Mac, you're asked for an administrator's password only when the app's folder needs it.

Older versions are left in place until nobody is using them, so updating doesn't disturb other people signed in to the same terminal server.

Preferences ▸ Updates

Edit ▸ Preferences ▸ Updates decides when PlanetPDF looks for updates by itself:

  • Check for updates on startup: a quiet check in the background soon after PlanetPDF starts (on by default).
  • Check for updates every N days while PlanetPDF is running (14 by default; 0 = Never).
  • Check Now checks straight away.

For IT: where people can't approve the administrator prompt (a terminal server, for example), run PlanetPDF.exe --install-updates as a scheduled task with administrator rights: it checks, downloads, and installs without asking.

Where your settings live

Everything that's yours in PlanetPDF is kept in one folder, your profile folder: your settings, saved signatures and initials, custom stamps, trusted certificates, your spelling dictionary, security policies, and logs. On Windows it's in your roaming profile (%APPDATA%\Planet Networks\PlanetPDF), so it follows you from computer to computer on a network that roams profiles; on a Mac it's in ~/Library/Application Support/Planet Networks/PlanetPDF.

To open it, choose Help ▸ Open Profile Folder. Edit ▸ Preferences ▸ General shows where it is, with an Open Folder button. An administrator can move it by setting the PLANETPDF_PROFILE_DIR environment variable.

A few things that are large or belong to one computer are kept in the computer's local application data instead: auto-save recovery copies, downloaded updates, and downloaded reading voices.

Dark mode and the display theme

Choose View ▸ Display Theme:

  • Follow System Setting: light or dark, as Windows (or macOS) is set.
  • Light.
  • Dark.

The same choice is in Edit ▸ Preferences ▸ Appearance. The theme changes PlanetPDF's menus, bars, and panels; the pages of your documents always show as they'll print.

Getting help

  • Help ▸ PlanetPDF Help (F1) opens this manual, with Contents, an Index, and Search. The same manual is PlanetPDF Manual.pdf in the install folder and on the Start menu.
  • Help ▸ Keyboard Shortcuts lists every shortcut, by menu (also in the manual: Keyboard Shortcuts).
  • Hover over any button to see what it does; many show their shortcut.
  • Edit ▸ Search More Tools… finds any command by name (see Search More Tools).
  • Help ▸ About PlanetPDF shows the version, what's new in each version, and the licenses of the parts PlanetPDF is built from.
  • When something goes wrong, see Troubleshooting.
