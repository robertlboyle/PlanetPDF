What's New

The changes in each version of PlanetPDF, newest first. Help ▸ About PlanetPDF shows the same list.

Version 0.1.17

  • Safer redaction: a redacted copy that fails any of its checks is no longer saved, and never replaces the original; the report offers Discard, or Save Anyway… after a second question. The checks now also fail when they can't run, and when a curved shape (text drawn as outlines, a drawn signature) is only partly under a box. Removing hidden information also removes the accessibility tags and alternate text, which can describe what was redacted. See Applying redactions.
  • Links in documents open only web pages and email: links to shared folders on other computers, to files, or that start programs are refused, and the question shows the site. See Links in documents.
  • Word, Excel, and PowerPoint files are converted with their macros turned off (Windows).
  • Digital signatures: a new setting checks online whether a signer's certificate was revoked (Preferences ▸ Signatures); a revoked one makes the signature invalid. Each signature says whether this was checked, and a timestamp that doesn't verify no longer counts.
  • Programs using PlanetPDF's API are asked about the first time, showing the program they really are, and their key works only for that program.
  • Updates are checked again on a copy only administrators can change, and never go back to an older version. These take effect with the update after this one.
  • Zoom: Ctrl+Shift+Plus always turns the view (it sometimes zoomed); Zoom In and Out step through the same levels each time (100, 125, 150, 200%…); typing a percentage in the zoom box and pressing Enter works.
  • The PlanetPDF printer no longer accepts connections from other computers, and network scanners' answers are checked more strictly.

Version 0.1.16

  • Click to type: with no tool chosen (also right after placing a signature, initials, or a stamp), a click on an empty spot of a page starts Add Text there. Turn it off in Preferences ▸ Documents ▸ Adding text. See Click anywhere to type.
  • Text you've typed before is suggested: as you add text, PlanetPDF offers the rest of something you typed earlier; Tab, Right, or End takes it, Up and Down show others, and Shift+Delete forgets one. The list stays on your computer, in your profile folder, and can be turned off or cleared in Preferences (Remembered text).
  • Help ▸ Report a Problem: starts an email to software@planet.net in your own email program, with the version and system filled in. Nothing is sent until you send it.
  • Updates: after you install a version with Setup, PlanetPDF no longer reports that an earlier attempt to update to it "wasn't installed".

Version 0.1.15

  • Mac: fixed PlanetPDF 0.1.14 closing as it started on Macs with macOS 26.2 or earlier. The Mac version now runs on macOS 15 (Sequoia) and later, and saving as PDF/A, PDF/X, PDF/E, and PostScript works on all of them. If 0.1.14 closes as it starts, download PlanetPDF.dmg again and replace it: it can't update itself.

Version 0.1.14

  • PlanetPDF for Linux: an AppImage, a .deb (Ubuntu, Debian), and an .rpm (Fedora, openSUSE), for PCs and for ARM64 computers. Everything works as on Windows and the Mac, including text recognition, PDF/A, signing, and Read Out Loud, and it updates itself (the .deb and .rpm ask for an administrator's password). The .deb and .rpm also add PlanetPDF's package repository, so the system's own updates include PlanetPDF. See Installing on Linux.
  • Mac: fixed a crash that could close PlanetPDF while it read a certificate from the Keychain.
  • Windows updates: when Windows' administrator prompt fails while an update installs, PlanetPDF no longer shows Windows' "File system error" box or reports the update as canceled: it says what happened and offers the download page for the full installer. If the update installed anyway, it says so. See The update wasn't installed.

Version 0.1.13

  • Screen readers: PlanetPDF works with Windows Narrator, NVDA, and other screen readers (VoiceOver on a Mac). Every button, box, list, and panel has a name the screen reader says; status messages and the progress of long jobs are read out; opening a file and turning pages are announced. See Accessibility.
  • Reading a page's text: Reflow (Ctrl+4) marks headings as headings, says where pictures are, and explains a page with no words (a scan). With a screen reader running, you can read it word by word; Ctrl+Page Down / Ctrl+Page Up turn pages.
  • Everything by keyboard: F6 / Shift+F6 move between the toolbars, the page, and the panels (Window ▸ Next Pane); the arrow keys go along a toolbar; a ring shows where the keyboard is. Forms are filled in from the Fill Form panel (choose a field, press Enter), comments are read, edited, and answered in the Comments panel, and stamps, signatures, and added text are placed with Enter and moved with the arrow keys.
  • Contrast themes and larger text: a Windows contrast theme now wins over PlanetPDF's own colors, icons included, and Preferences ▸ Appearance ▸ Text size makes the program's text up to twice as large.
  • Preferences: Tab starts at the list of pages, as you see it.
  • Fill & Sign circles: drag from one corner to the other to draw a circle or any oval (hold Shift for a perfect circle). The ▾ beside the circle button chooses Outline or Solid Fill and the line width, and the line keeps its width when you resize the circle. See Symbols.
  • Symbols keep their size: once you resize a check mark, cross, circle, line, or dot, the next ones of that kind are placed at the same size, until you resize one again.
  • Tool bars stay put: a tool's buttons start right after its name and no longer shift around when a tool shows more options.
  • On the Mac (the first Mac release since 0.1.1, with everything above): PDF from Scanner works with USB and network scanners; Word, Excel, and PowerPoint files become PDFs through Office for Mac; Digital IDs in the Keychain sign, open certificate-protected files, and are trusted; Read Out Loud uses the Mac's own voices and offers to download the natural voices; PDF from Web Page finds Chrome, Edge, Chromium, and Brave; Helvetica, Avenir, Menlo, and the Mac's other font collections are offered; and a printer's problem (offline, out of paper, paused) is named.
  • Installer: Setup's button on the taskbar shows the PlanetPDF icon instead of a blank program icon.

Version 0.1.10

  • Security fix: PlanetPDF now uses Pillow 13.0.0, which fixes three critical security problems in the picture library it relies on. One of them could be reached when Compress PDF or Optimize Scans turned a scanned page into black and white: a specially made scan could crash PlanetPDF or worse. Installing this version is recommended.

Version 0.1.9

  • Fixed: Setup started an older PlanetPDF. When Setup asked which app opens PDF files, it could start the version installed before (0.1.0) instead of the new one. It now always starts the version it has just installed.
  • Installer: the desktop shortcut is ticked by default, and every task starts ticked each time you install, also over an older version. The tips while installing show menu names correctly ("Fill & Sign", "Scan & OCR").

Version 0.1.8

  • Barcode fields: a new Barcode tool in Prepare Form makes a QR code or PDF417 barcode of the form's answers, drawn again whenever an answer changes. See Barcode fields.
  • Field detection finds more blanks: the usual form labels without a colon ("Date of Birth", "Phone"), placeholders such as "MM/DD/YYYY", "(___) ___-____", and "$______", and the empty cells of tables meant to be filled in (a price list full of data is left alone). See What auto detection finds.
  • Edit PDF: a line whose words use different fonts (a bold word in a sentence) opens as one line; each word keeps its font, and words you type take on the font of the word beside them. See Editing text in place.
  • Text drawn as outlines can be made searchable: Recognize Text lists such pages with the scanned ones. Words that are already real text aren't added twice.
  • Progress you can see: Find counts the pages of a long document as it searches and has Stop; saving a long document shows each step; Find Text & Redact counts too. Applying redactions, splitting, and the comparison report run in the background, so the window keeps drawing.
  • Fonts on Windows: fonts that come in collections (Cambria's regular style, MS Gothic, Yu Gothic, SimSun, Microsoft YaHei, and others) are offered in the font lists.
  • The right pointer everywhere: after Add Text and Enter the I-beam comes back; the Select arrow shows the I-beam over text; text form fields show the I-beam and buttons the pointing hand; the Pencil shows a pen and Marquee Zoom a magnifier. See What the pointer shows.

Version 0.1.7

  • Installer: the Windows installer shows PlanetPDF's own pictures instead of the installer's standard ones, and while the files are copied it shows tips about what PlanetPDF can do, a new one every few seconds (Next tip shows the next one at once).
  • Fixed: making PlanetPDF the default app for PDF files. Instead of Windows' "How do you want to open .pdf files?" window, you only got a message sending you to Settings. Now the window opens: choose PlanetPDF and click Always. When PlanetPDF already opens your PDF files, the installer and Preferences simply say so. See PDF files.
  • The PlanetPDF printer: if a printout fails, Windows keeps it in the printer's queue and holds up every printout after it. The manual now explains how to clear it (see The PlanetPDF printer shows an error or nothing comes out), and the printer's log says more about what it turned away.

Version 0.1.6

  • Add Text: Enter finishes the text and Shift+Enter starts a new line. Text you've just added is no longer left selected, so its handles don't hide where it sits.
  • Fixed: choosing another tool (a signature, for example) left the last item's handles showing. Choosing a tool now clears the selection.

Version 0.1.5

  • AI text reading for exports: exports to Word, Rich Text, text, and HTML can read the pages with Unlimited-OCR, an AI model, for one flowing document with headings, paragraphs, lists, and tables. It needs the optional PlanetPDF AI Text Reading add-on and an NVIDIA graphics card with about 8 GB of memory. See AI text reading.
  • Fixed: a file opened while PlanetPDF was still starting could start a second copy of PlanetPDF, so one file could be open twice and closing one copy didn't ask about the other's changes. Now a file is only ever open in one PlanetPDF.

Version 0.1.4

  • Text tools: Highlight, Underline, Strike-Out, Replace Text, and Text Callout show the I-beam over text and a crosshair elsewhere. With the marking tools, start a drag off the text to draw a box: every word it touches is marked.
  • Edit PDF: the first button is now a Select arrow, for picking what's already on the page to change it.
  • Eraser: a Width box appears on the Edit PDF bar while the Eraser is on. Fixed: with a line selected, the Eraser moved it instead of erasing it.

Version 0.1.3

  • Fixed: the Windows taskbar showed a generic icon for PlanetPDF instead of its own.

Version 0.1.2

  • The PlanetPDF printer: print from any program to the "PlanetPDF" printer and the document becomes a PDF. PlanetPDF asks whether to open it afterwards (you can have it remember your answer), then where to save it, starting in the folder you used last. Preferences ▸ Documents can set a folder and a file name pattern so it saves without asking. It works for each person on a terminal server. On a Mac, choose Open in PlanetPDF from any print dialog's PDF menu.
  • A manual: this help, with Contents, an Index, and Search (F1), also as a PDF in the install folder.
  • Scripts and other programs: every function can be used from a command prompt (planetpdf help), from other programs through PlanetPDF's local API, and by plugins that add their own menu commands. Signing always asks you first. See Scripts, Programs, and Plugins.
  • Tools stay on until you choose another tool or close the tool; tools for one thing (a stamp, a signature, Attach File, Add Image) switch off after it. The tool that's on is highlighted.
  • Choosing PlanetPDF for PDF files: the installer now opens Windows' "How do you want to open .pdf files?" window, where you pick PlanetPDF.
  • Fixed: page thumbnails jumping between two sizes on some files; deleting and reordering pages in the Pages panel while editing; PDF from Web Page failing on some computers.

Version 0.1.1

  • Faster start and less memory; tool bars are made when first used.
  • A native launcher that starts PlanetPDF quicker.
  • Preferences in pages down the left; the page cache size and when to check for updates are settings.

Version 0.1.0

The first version: viewing, organizing pages, editing, comments, stamps, forms, signatures, digital signing, protection, redaction, scans and text recognition, creating and exporting, PDF standards, comparing, printing, and updates.
