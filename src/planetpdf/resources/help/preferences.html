Preferences

Preferences hold the settings that apply to all your documents: your name for comments and stamps, how PlanetPDF looks, how much memory it uses, auto-save, the PlanetPDF printer, digital signatures, Read Out Loud, scripts and plugins, and updates. This chapter goes through every page and every setting.

Opening Preferences

  1. Choose Edit ▸ Preferences… or press Ctrl+, (on a Mac, Preferences is in the PlanetPDF menu, ⌘,).
  2. Click a page in the list on the left: General, Appearance, Performance, Documents, Signatures, Read Out Loud, Scripting & Plugins, or Updates.
  3. Change what you need and click Save. Cancel leaves everything as it was.

Changes apply to every open PlanetPDF window as soon as you click Save. While PlanetPDF runs, Preferences opens on the page you looked at last.

Grayed settings. On a computer your company looks after, IT can set some settings for everyone who uses it. Those are shown as IT set them, grayed, and resting the pointer on one says Set by your administrator for everyone on this computer; a line at the bottom of Preferences says so too. What you had chosen yourself is kept and comes back if IT removes its setting. See the policy file.

Profile folder

Shows the folder that holds your PlanetPDF settings, saved signatures and initials, stamps, trusted certificates, spelling dictionary, plugins, and logs. Open Folder opens it (so does Help ▸ Open Profile Folder). See Where settings are stored.

PDF files

In an installed copy of PlanetPDF, Make PlanetPDF the Default App for PDF Files… makes double-clicked PDFs open in PlanetPDF:

  • Windows doesn't let a program make itself the default, so this opens Windows' own "How do you want to open .pdf files?" window. Choose PlanetPDF there and click Always. (The installer offers the same window when you install.)
  • Mac: PlanetPDF becomes the default straight away. (The Mac app also asks once, the first time it starts.)

When PlanetPDF already opens PDF files, the button reads PlanetPDF Opens PDF Files and is grayed.

Appearance

Theme: Follow System Setting (the default: light or dark like Windows or macOS), Light, or Dark. This is the same as View ▸ Display Theme. Only PlanetPDF's windows change; the pages of your documents always show as they will print. While Windows uses a contrast theme, PlanetPDF uses its colors instead (see Contrast themes).

Text size: Normal (the default), 125%, 150%, 175%, or 200%: larger text in the menus, toolbars, panels, and dialogs (see Larger text).

Documents

Recovery

Auto-save for recovery every: while a document has unsaved changes, PlanetPDF keeps a recovery copy of it on this computer this often. If PlanetPDF closes unexpectedly, it offers the copy back the next time it starts (see PlanetPDF closed unexpectedly). The recovery copy never replaces your file, and it keeps the file's password protection. From 1 to 60 minutes, or Off. Default: 5 min.

Note: auto-save is not the same as saving. Your file changes only when you choose File ▸ Save.

Adding text

  • Clicking the page with no tool chosen adds text there: a click on an empty spot of a page, with the Select arrow (also right after placing a signature or stamp), starts typing there, as Add Text does. See Click anywhere to type. Default: on.
  • Remember the text I add and suggest it as I type: see Remembered text. Off: nothing new is remembered and nothing is suggested (what's already remembered stays until you forget it). Default: on.
  • Also remember text with Social Security, card, or account numbers: off (the default), text holding what looks like one of those numbers is never remembered, and switching this off forgets any that was. Default: off.
  • Forget Remembered Text (count) empties the list at once.

Scripting & Plugins

This page controls which other programs and plugins may use PlanetPDF. See Scripts, Programs, and Plugins for what they are.

Command line and local API

Let other programs and plugins use PlanetPDF (its local API): off by default (turning a plugin on turns it on). Only programs on this computer, running as you, can connect, and signing always asks you first. A change takes effect the next time PlanetPDF starts. The command line (planetpdf help) works either way.

Programs that have used PlanetPDF

Each program (and plugin) that has connected is listed with when it was last used and its signing state: asks first, allowed (you chose "Always Allow This Program"), or blocked. Select one and click:

  • Block / Unblock: refuse everything it asks for, or allow it again.
  • Stop Signing: it will be asked again the next time it wants to sign.
  • Remove: forget it. Its key stops working; it can introduce itself again.
  • Activity Log…: what each program did, when, with which files, and how it ended (passwords are never recorded).

Plugins

Every plugin found is listed with what it asks to do. Tick one to turn it on: PlanetPDF shows what it asks for and what it adds to the menus, and turns it on only when you click Yes. Untick it to turn it off. A plugin whose files have changed since you turned it on is off again ("changed since you turned it on: turn it on again to use it"). The page shows the folder to put plugins in.

Where settings are stored

Everything that belongs to you is kept in one profile folder:

  • Windows: %APPDATA%\Planet Networks\PlanetPDF (the Roaming part of your Windows profile, so it follows you from one terminal server or computer to another).
  • Mac: ~/Library/Application Support/Planet Networks/PlanetPDF
  • Linux: ~/.local/share/Planet Networks/PlanetPDF

It holds settings.json (these preferences), your saved signatures and initials, stamps and seals, trusted certificates, security policies, your spelling dictionary, the text you've added (text-history.json, for suggestions), plugins, the list of programs allowed to use PlanetPDF, and the logs folder.

Some things are kept only on this computer, in the local (not roaming) app data folder (Windows: %LOCALAPPDATA%\Planet Networks\PlanetPDF): auto-save recovery copies, downloaded updates, downloaded voices, and printouts waiting to be saved.

IT can put the profile folder somewhere else by setting the environment variable PLANETPDF_PROFILE_DIR to a folder.

Tip: to start over with default settings, close PlanetPDF and rename settings.json in the profile folder. Your signatures and stamps stay.
