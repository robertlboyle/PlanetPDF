Troubleshooting

What to do when something doesn't work as expected: PlanetPDF won't start, a file won't open or save, a printer, scanner, or Office conversion fails, and how to report a problem so it can be fixed.

PlanetPDF won't start, or its window can't be seen

The window is off the screen. Your settings follow you between computers, so PlanetPDF may remember a window position on a monitor this computer doesn't have. PlanetPDF checks this when it starts and moves the window to the middle of the main screen when too little of it would show. If the window still seems missing, look for PlanetPDF on the taskbar, click it, and press Win+Up to maximize it.

Starting it again does nothing. Only one copy of PlanetPDF runs for you at a time. Starting it again (or double-clicking a PDF) brings the running copy forward and opens the file there as a new tab. If that copy has stopped responding, end PlanetPDF in Task Manager (Ctrl+Shift+Esc) and start it again; unsaved changes can be recovered (see below).

It closed or froze while starting. Start it again. When the previous start didn't finish, PlanetPDF skips your saved toolbar and panel layout once, which fixes a start that a damaged layout was stopping. If it still won't start, send the startup log (see The log files).

PlanetPDF closed unexpectedly: getting your work back

While a document has unsaved changes, PlanetPDF keeps a recovery copy every few minutes (every 5 minutes unless you changed it in Preferences ▸ Documents). If PlanetPDF closes unexpectedly, the next start shows Recover Unsaved Work with each document and when it was auto-saved:

  • Restore saves the recovered copy as "name (recovered).pdf" next to the original (in your Documents folder if that folder is gone) and opens it. The original file is not changed. To see what differs, open both and use View ▸ Compare Files.
  • Discard throws the unsaved changes away (it asks first).
  • Decide Later keeps the copies and asks again at the next start.

File ▸ Reopen PDFs from last session opens again every document that was open when PlanetPDF last closed.

When a command fails without PlanetPDF closing, you see a message saying it "didn't work, and nothing was changed", with the name of the log file that holds the details.

The log files

PlanetPDF writes what happens into the logs folder of your profile folder (choose Help ▸ Open Profile Folder, then open logs):

  • startup.log: each step of the last start with the time it took, your screens, and where the window was placed. If a start hangs, it notes every 15 seconds where it is stuck. It is replaced each time PlanetPDF starts, so copy it before starting again.
  • planetpdf.log: the details of every error PlanetPDF reported to you, with the date and time.
  • api-audit.log: what scripts and other programs did through PlanetPDF (see Scripts, Programs, and Plugins), and a plugins folder with each plugin's output.

A printer doesn't respond

PlanetPDF checks a printer in a separate helper program before using it, because some printer drivers freeze or close a program when the printer can't be reached. If the check fails you get a message saying why, and PlanetPDF offers Microsoft Print to PDF instead. Turn the printer on, check its cable or network connection, and print again, or pick another printer. Each message is explained in What the printer messages mean.

The PlanetPDF printer shows an error or nothing comes out

If one printout fails, Windows keeps it at the front of the PlanetPDF printer's queue marked Error, and every printout after it waits behind it. The printer then shows an error, and a web browser may hang on "Waiting for printer connection" or leave PlanetPDF out of its list. To clear it:

  1. Open Windows Settings ▸ Bluetooth & devices ▸ Printers & scanners, choose PlanetPDF, then Open print queue.
  2. Right-click the job marked Error and choose Cancel. (Your own jobs need no administrator; other people's do.) The document you printed isn't touched: only the failed printout goes.
  3. Close and reopen the program you print from (a web browser remembers its printer list), then print again.

If printouts keep failing, give IT the PlanetPDF printer's log (see Reporting a problem).

A file won't open

The file asks for a password

PlanetPDF shows Password Required. Type the document's open password and click OK; if it is wrong, you are asked again. Click Cancel to give up. Only the person who protected the file can tell you the password: PlanetPDF can't open it without.

The file is encrypted for certain people

A file protected with certificates opens only with the Digital ID it was encrypted for. PlanetPDF first tries the Digital IDs in your Windows certificate store (on a Mac, your Keychain); if none fits, it asks for a Digital ID file (.pfx or .p12) and its password. If none of yours fits, ask the sender to encrypt it for you.

The file is damaged or isn't a PDF

If you see Can't Open File, the message says what's wrong. Common causes: the download or e-mail attachment was cut short (download it again), the file is still being copied or synced (wait and try again), or it isn't a PDF despite its name. Forms made only for Adobe's dynamic XFA format can't be shown; PlanetPDF says so.

Save fails: the file is in use

If you see Save Failed with "Access is denied" or "being used by another process", something else has the file open or locked:

  • Close the file in other programs (Adobe Acrobat, a browser, Outlook's preview pane, a second copy on another computer).
  • A sync program (OneDrive, Dropbox) may be uploading it: wait a moment and save again.
  • The file or folder may be read-only, or you may not be allowed to change files in it.

Your changes are still in PlanetPDF. If saving keeps failing, use File ▸ Save As… to save a copy somewhere else, such as your Documents folder.

A file I was working on disappeared

A file opened from inside a zip file or an e-mail is a copy in a temporary folder, and it goes when the zip window or the e-mail program closes. PlanetPDF 1.0.2 and later won't save there (see Files from a zip file or an e-mail). If it happened with an older version:

  • The original is still where it came from: open the zip file or the e-mail again.
  • If PlanetPDF was still open with unsaved changes, or closed unexpectedly, start PlanetPDF: it offers its recovery copy (see getting your work back).
  • Changes that were saved into the temporary folder are gone with it; Windows doesn't put such files in the Recycle Bin.

Text can't be selected, searched, or copied

  • Scanned pages are pictures of paper, with no text in them. Open the Scan & OCR tool and use Recognize Text; PlanetPDF adds invisible text you can then search, select, and copy (see Scans, Text Recognition, and File Size).
  • Text turned into outlines (common in brochures and some design programs) is drawn as shapes. It looks like text but can't be found or selected until you use Recognize Text, which lists such pages with the scanned ones. To change the words themselves, ask for the original file.
  • Hidden layers: text on a layer that is switched off can't be found.

Fonts look different

A PDF can name a font without including it. PlanetPDF then shows it with a similar font, and when you save, it includes any such font that is installed on this computer so the file looks right everywhere. The status bar names the fonts that aren't on this computer. When you edit text in a font PlanetPDF doesn't have, or one the document includes only partly (only the letters it used), PlanetPDF uses the closest standard font and says so. To keep the exact look, install the font on the computer, or edit the text with a font you have.

Read Out Loud is slow or silent

  • The first words take a while. The first time, the voice has to load ("Please wait…" in the status bar). The natural voices take a few seconds.
  • The voice pauses between sentences. The Kokoro voices need a fast computer. Choose Automatic or Piper in Preferences ▸ Read Out Loud; Automatic measures this computer and uses Kokoro only when it reads smoothly.
  • No sound. Check the volume slider on the Read Out Loud toolbar, your computer's volume, and which speakers or headset are in use. If a voice can't be used, PlanetPDF shows a message saying why rather than staying silent; try another engine in Preferences.
  • Natural voices aren't listed. They are a separate download: Download Natural Voices (354 MB)… in Preferences ▸ Read Out Loud.

Office conversions fail

Making PDFs from Word, Excel, and PowerPoint files, and exporting to Word 97-2003 (.doc), use Microsoft Office on this computer.

  • Office isn't installed: these conversions aren't available. Exporting to Word (.docx), Excel, and PowerPoint doesn't need Office.
  • Word 97-2003 is blocked: your company's Microsoft 365 policy can block the old .doc format, and PlanetPDF tells you so. Export as a Word Document (.docx) instead. Only IT can change that policy.
  • On a Mac, macOS asks once whether PlanetPDF may control Word (or Excel, PowerPoint), and once whether it may access data from other apps. Click OK / Allow. If you refused, allow it in System Settings ▸ Privacy & Security ▸ Automation ▸ PlanetPDF, then try again. When Word was already open, the converted copy stays open there, named "name (PlanetPDF copy)"; close it yourself.

The AI text reading box is grayed out, or the AI stops

Point at the grayed box in the Export window (or look at Preferences ▸ Performance): it says why.

  • The add-on isn't installed: run PlanetPDF-AI-Setup (keep its .bin files beside it).
  • No NVIDIA graphics card was found: it needs one, with a current NVIDIA driver; Intel and AMD graphics can't run it. Export without the AI instead.
  • Too little memory on the card: it needs about 8 GB.
  • "The AI text reader stopped unexpectedly": usually the card ran out of memory (another program using it, or a very long document). Close other programs that use the graphics card, or export fewer pages at a time.

Making a PDF from a web page fails

  • It needs Microsoft Edge or Google Chrome (on a Mac, also Chromium or Brave). Install one if neither is found.
  • Type a web address (www.example.com becomes https://www.example.com) or a file on your computer. Other kinds of addresses are refused.
  • The page is loaded in a fresh browser that isn't signed in to anything, so pages behind a sign-in come out as the sign-in page. Save such pages from your own browser with the PlanetPDF printer instead (The PlanetPDF printer).
  • PlanetPDF waits up to 2 minutes, counting the seconds; click Cancel to stop sooner. A slow site may need another try.

A scanner isn't found

  • Windows uses Windows' own scanning. Check that the scanner is on and shows in Windows Settings ▸ Printers & scanners; install its driver if not.
  • Mac: on first use, macOS asks whether PlanetPDF may find devices on your local network. Click Allow. If you didn't, turn PlanetPDF on in System Settings ▸ Privacy & Security ▸ Local Network. USB scanners and network scanners both appear in the list.
  • In the scan window, click Find Again (network scanners sometimes answer late), or Add by Address… and type the scanner's network address (ask IT).

Updates

PlanetPDF checks for updates as set in Preferences ▸ Updates, and any time you choose Help ▸ Check for Updates…. When a new version is out, PlanetPDF asks before it downloads it (Download, Not Now, or Skip This Version). The download is checked (it must carry Planet Networks' signature and match its checksum, or it isn't used). When it is installed, the installing step checks it again on a copy only administrators can change, never installs a version older than the one you have, and installs only into the PlanetPDF it runs from (the one the installer registered). An update also brings new versions of the PlanetPDF printer's service and of the program that starts PlanetPDF, when they changed; the print service is stopped for a moment while it's replaced. Then you choose:

  • Restart Now: PlanetPDF closes every window (asking about unsaved work), installs, and starts again.
  • When I Close PlanetPDF: installs the next time you close it.
  • Not Now, or closing the question: nothing is installed; you're asked again at the next check.
  • Skip This Version: not asked about this version again.

Installing needs administrator rights, so Windows shows one User Account Control prompt. Each version is installed in a folder of its own, so other people still using the old version on a shared computer aren't disturbed; old versions are removed once nobody uses them.

Terminal servers and computers without administrator rights. Users who can't answer the UAC prompt can't install updates themselves, so PlanetPDF only tells them once that a new version is out, and doesn't download it. IT can install them with no questions by running, as an administrator or as a scheduled task under SYSTEM:

& "C:\Program Files\PlanetPDF\PlanetPDF.exe" --install-updates

On a Mac, the update replaces the app; macOS asks for an administrator password only if the Applications folder isn't writable for you.

"…is still from an older version"

Two programs live beside PlanetPDF's versions rather than inside one: the small program that starts PlanetPDF, and the PlanetPDF printer's service. An update installed by PlanetPDF 1.0.6 or older replaced only the version itself, so after such an update those two can still be the old ones. PlanetPDF notices when it starts and says so, once for each version:

  • If you can approve Windows' administrator prompt, click Update Now and answer the prompt: PlanetPDF replaces them with the ones this version came with and tells you when it's done. Not Now, or closing the question, changes nothing.
  • If you can't, the message says to ask whoever looks after the computer. They can run PlanetPDF's installer for this version, or, as administrator, PlanetPDF.exe --refresh-install "C:\Program Files\PlanetPDF".

PlanetPDF itself works as usual meanwhile; what's missing are the newer print service's and launcher's own fixes.

The update wasn't installed

When PlanetPDF starts after an update that didn't install, it says why:

  • The administrator prompt was canceled: PlanetPDF offers the update again at its next check, or choose Help ▸ Check for Updates….
  • Windows couldn't start the update's installer as administrator: on some Windows 11 computers the administrator prompt itself fails (sometimes with a "File system error (-1073740791)" box). Click Open Download Page, download PlanetPDF-Setup.exe, and run it: it installs the new version over the old one and keeps your settings.

Each step of an update is written to update.log in %LOCALAPPDATA%\Planet Networks\PlanetPDF\updates; include it when you report a problem.

Note: the update is installed by the version you're updating from. Copies of 0.1.13 and older can still show Windows' "File system error" box and then say the prompt was canceled; if that happens, install the new version with PlanetPDF-Setup.exe from the download page. PlanetPDF 0.1.14 can show that message once, from an earlier attempt, even though it's installed; from 0.1.15 on, PlanetPDF doesn't report a failed update once the version it was for (or a newer one) is installed.

The self-test

The self-test checks that an installed copy of PlanetPDF has everything it needs: every part loads, the bundled files are there, and text recognition, PDF/A conversion, spelling, and the voices really work. In PowerShell:

& "C:\Program Files\PlanetPDF\PlanetPDF.exe" --self-test "$env:USERPROFILE\Desktop\self-test.txt"

Wait about a minute until self-test.txt appears on your desktop. Each line starts with OK, SKIP (an optional part that isn't installed, such as the natural voices), or FAIL with the reason. Any FAIL means the installation is incomplete: reinstall PlanetPDF, and send the report if it fails again.

Reporting a problem

Send bug reports and suggestions by email to software@planet.net. Help ▸ Report a Problem starts that email in your own email program, with PlanetPDF's version and your system already filled in and headings for what happened, what you expected, and how to make it happen again; nothing is sent until you send it. PlanetPDF never sends anything by itself: you decide what goes in your email, and it's used only to look into what you reported. There's no promised support, but we intend to fix reported bugs quickly.

To get a problem fixed quickly, include:

  1. What you did, step by step, what you expected, and what happened instead.
  2. The exact message, or a screenshot of the PlanetPDF window (not the whole screen).
  3. The PlanetPDF version: Help ▸ About PlanetPDF.
  4. planetpdf.log and, for problems starting, startup.log: Help ▸ Open Profile Folder, then the logs folder.
  5. The PDF it happened with, if it isn't confidential.
  6. For an installation problem, the self-test report. For the PlanetPDF printer, IT can add %ProgramData%\PlanetPDF\Spool\printer.log.

Note: the log files never contain passwords.
